Instalar a Biblioteca como aplicativo

O instalador cria um atalho Biblioteca na Área de Trabalho e no menu Iniciar. Ele abre o sistema numa janela própria, sem barra de endereço nem abas, como um programa. Faça isso uma vez em cada computador.

Windows

  1. Clique em Baixar instalador para Windows
  2. Abra o arquivo baixado (instalar-atalho-biblioteca.bat). Se o Windows mostrar "O Windows protegeu o computador", clique em Mais informações › Executar assim mesmo.
  3. Pronto: o atalho aparece na Área de Trabalho e o sistema já abre como aplicativo. Se quiser, clique com o botão direito no ícone da barra de tarefas › Fixar na barra de tarefas.

Usa o Microsoft Edge (que já vem no Windows) ou o Google Chrome. Não precisa ser administrador.

Linux

  1. Clique em Baixar instalador para Linux
  2. No terminal, rode: sh ~/Downloads/instalar-atalho-biblioteca.sh

Precisa do Chrome, Chromium ou Edge instalado.

Outra forma (sem baixar nada)

No Chrome ou no Edge: menu ⋮ › Transmitir, salvar e compartilhar › Criar atalho… (no Edge: Aplicativos › Instalar este site como um aplicativo) e marque Abrir como janela.
